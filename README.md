# React Event Handlers Demo

An interactive React application demonstrating all common React event handlers with visual feedback.

## 🎯 Features Demonstrated

- **Mouse Events** (10 events) - Click, right-click, double-click, hover, drag, wheel with ripple effects
- **Keyboard Events** (3 events) - Key press tracking with visual feedback
- **Form Events** (5 events) - Change, input, submit, reset, select with live preview
- **Focus Events** (2 events) - Focus and blur with indicators
- **Touch Events** (4 events) - Touch start, move, end, cancel (mobile-friendly)
- **Clipboard Events** (3 events) - Copy, cut, paste with notifications
- **Scroll Events** - Scroll position tracking with progress bar
